# Bee Dsx Real Case

This case retains seven selected Dsx-family loci, represented in the upstream
protein set by these transcript identifiers: *Apis cerana* XM_062075842.1,
*A. mellifera* NM_001111255.1, *Bombus ignitus* ENSBIGT00000022497,
*B. pascuorum* XM_060970849.1, *B. terrestris* XM_048406069.1,
*Frieseomelitta varia* XM_043654866.1, and *Tetragonisca angustula*
g10177.t1. All seven selected accessions occur in orthogroup OG0009654 of an
OrthoFinder 3.1.5 analysis of 44 bee species.
This provides group membership support for the selected accessions; the group
also contains additional species members and duplicate/isoform sequences, so it does not by
itself establish one-to-one orthology or an exon-event history. The OG0006454
label in the case manifest has not been traced to its source orthogroup
dataset. The supplied seven-species tree is consistent with pruning the
current OrthoFinder species tree while preserving path lengths.

All annotated transcripts are retained for structural display. Formal
phylogenetic states are locus-level observations from genome sequence and
annotation; transcript-specific sex usage is outside the available data and is
not inferred.
