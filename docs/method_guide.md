# Genomic exon-span method guide

The plates in this guide are synthetic illustrations generated by the
explanation renderer. They are not visualizations of an empirical run.

## Default model scope

The default `analyze` model is `exon-structure-ctmc`. Its local state combines
one ordered geometry of annotated physical exon spans—including annotated
terminal and UTR exons—with presence states for declared local DNA material
tracts. It does not include hidden RNA-use, transcript-repertoire, or splicing
states. An exon boundary does not establish splice-site function.

The default fit estimates one nonnegative rate per family, shared across its
elementary edit kinds and linked local units. It does not pool one fitted scale
across a prespecified set of independent genes. The finite geometry catalogue
is conditional on observed and declared candidates; no state-count cap is
imposed by default. Explicit state or origin-scenario limits stop inference
when reached.

## Correspondence and structural illustrations

![Correspondence](figures/homology_inference.svg)

Sequence, coordinates, strand and local order support correspondence. Conflicts
and insufficient support remain unresolved. The diagram is conceptual and does
not represent joint alignment inference or a transcript-usage assay.

![Overview](figures/method_overview.svg)

The split, fusion, boundary and DNA-change motifs illustrate possible local
edit-graph transitions. They do not assert that any specific path or molecular
mechanism was inferred. Whole-annotation alternatives and local transcript
repertoires shown in broader figures belong to separate model scopes; they are
not states of the default genomic exon-span model.

![Model](figures/phylogenetic_model.svg)

The tree and rates in this synthetic example are illustrative and are not fitted
biological estimates. Parsimony panels are separate summaries, not the default
`analyze` estimator. The default CTMC branch table reports endpoint net-change
probabilities and joint modal endpoint configurations. It does not infer a
trajectory or transition count. `--expected-edits` optionally writes model-based
conditional transition counts.

## Results and interpretation

`intraphy visualize` does not currently render results from
`exon-structure-ctmc`. Use the native fit, diagnostics, history, summary and
`branch_exon_changes.tsv` outputs described in the
[genomic exon-span model](genomic_exon_model.md). Tied joint endpoint rows are
alternative endpoint explanations, not event counts.

The default exon model's local DNA-material process is distinct from the
advanced source-directed DNA-copy model, which has its own state and event
catalogue. See the [DNA-copy model reference](exon_structure_model.md).
